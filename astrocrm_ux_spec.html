Принципы UX
Progressive disclosure
Простой режим — 4 карточки. Профи — полный набор вкладок.
Compensatory inline
Практики раскрываются прямо под транзитом по клику ↓. Не отдельный экран.
Один запрос
POST /full-profile или POST /dashboard — всё одним вызовом.
Карточки транзитов
Цветовая точка: красная = напряжение, зелёная = гармония, синяя = слияние. Орб в °.
VoC индикатор
Оранжевый бейдж в карточке Луны. Время начала VoC + следующий знак.

Критические баги — исправлены в v2
Дубль POST /daily/personal (L1191 vs L4287)
Удалена старая версия L1191–1320 (без compensatory). Осталась L4287 с фирдари + профекции + компенсаторика.
Дубль GET /ephemeris/ingress-calendar (L1322 vs L4416)
Удалена старая версия L1322–1423. Осталась одна.
/predictive/perfections — неверное имя
Переименован в /predictive/exact-aspects. Функция вызывала transit_exact_dates() — это «точные даты аспектов», не «перфекции».
/report/generate не вызывал compensatory
Добавлен блок SECTION 10 + HTML-секция 🛠 «Компенсаторные практики» в HTML-шаблон отчёта.
Добавлены /full-profile и /couple/*
POST /full-profile — агрегирует всё (natal + transits + compensatory + timing). /couple/forecast|timeline|compare — алиасы /interaction/* с понятными именами.
Архитектурные проблемы — рекомендации
/interaction/* vs /couple/* — путаница назначений
5 эндпоинтов /interaction/* — прогностика для двух людей, не для одного. Добавлены /couple/* алиасы. Рекомендовано переименовать в основном коде.
/predictive/tertiary и /predictive/converse — слишком сложные
Третичные и конверсные прогрессии — advanced-техники. Добавлен docstring. Рекомендовано скрыть за ?advanced=true param в следующем спринте.
Human Design не в /dashboard
9 HD-эндпоинтов существуют, но /dashboard их не включает. В /full-profile добавлен параметр include_human_design=true.
CORS — проверить ALLOWED_ORIGINS env
В коде настроен через env ALLOWED_ORIGINS. На production-сервере Railway убедитесь, что переменная задана явно (не «*»).
pyswisseph не установлен → деградация точности
Без Swiss Ephemeris точность падает до ~5'. Критично для первичных дирекций, ректификации. Проверить /health → se_ok: true.
POST /full-profile НОВЫЙ в v2
Агрегирует всё необходимое для главного дашборда одним запросом. Заменяет цепочку natal → transits → compensatory → profections → firdaria.
