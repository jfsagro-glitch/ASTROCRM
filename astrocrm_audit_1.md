### 1. ✅ РЕАЛИЗОВАНО — Профекции vs Фирдарии — разные техники
**Коммит:** `78e9b02` | **Файлы:** `astro_predictive.py`, `astro_api.py`

**Файл**: `astro_predictive.py`, эндпоинт `POST /predictive/profections`

**Проблема**: В описании написано «Фирдарии / профекции по домам» — это два
совершенно разных инструмента, объединённых в один эндпоинт.

- **Профекции** — ежегодная активация домов (H1 в 0 лет, H2 в 1 год, ...H12 в 11,
  H1 снова в 12). Управитель годового дома становится «Лордом года».
- **Фирдарии (Firdariyyat)** — планетарные периоды из эллинистической астрологии,
  длительности зависят от секты (дневная/ночная карта), порядок по убыванию орбит.
  Дневная: ☉7 → ♀8 → ☿13 → ☽9 → ♄11 → ♃12 → ♂7. Ночная: ☽9 → ♄11 → ☿13 → ...

**Исправление**: разделить на два эндпоинта:
```
POST /predictive/profections   — только профекции           ✅ было, оставлено
POST /predictive/firdaria      — только фирдарии (добавить) ✅ добавлено
```
Реализована полная функция `firdaria()`: определение секты по Солнцу, порядок планет
дневной/ночной, 7 подпериодов внутри каждого главного, полное расписание на 120 лет,
текущий активный период + подпериод.

### 2. ✅ РЕАЛИЗОВАНО — Алгоритм затмений — неточная классификация
**Коммит:** `a1ceff4` | **Файл:** `astro_predictive.py`, функция `find_eclipses()`

**Файл**: `astro_predictive.py`, функция `find_eclipses`

**Проблема 1 — солнечные затмения**: 
Классификация только по расстоянию до узла не может различить полное vs кольцеобразное.
Для этого нужно сравнивать угловые диаметры Луны и Солнца (требует расстояния до Луны).
Текущая классификация «Полное/Кольцеобразное» при dist_node < 10° — ошибочная метка.

```python
# Текущий код (НЕВЕРНО):
if dist_node < 10°:
    type = "Полное/Кольцеобразное"

# Правильно — добавить проверку расстояния Луна-Земля:
lunar_distance = calc_lunar_distance(jd)  # в км
moon_angular_diameter = 2 * atan(1737.4 / lunar_distance)
sun_angular_diameter = 2 * atan(696000 / calc_sun_distance(jd))
if moon_angular_diameter >= sun_angular_diameter:
    eclipse_subtype = "total"
else:
    eclipse_subtype = "annular"
```

**Исправлено частично**: без `calc_lunar_distance` полное/кольцеобразное по-прежнему
неразличимы. Лейбл исправлен с `"total/annular"` → `"central"` с явным комментарием
в коде. Полная реализация потребует добавления `calc_lunar_distance()`.

**Проблема 2 — лунные затмения**:
Порог для полутеневого лунного затмения — не 12.5°, а ~14°.
Стандартные пороги (NASA):
- Полное лунное: dist_node < 4.6°
- Частное лунное: dist_node < 9.5°  
- Полутеневое лунное: dist_node < 14.0°  ← исправлено с 12.5° ✅

### 3. ✅ РЕАЛИЗОВАНО — Arabic Parts — неверная формула Части Брака
**Коммит:** `a1ceff4` | **Файл:** `astro_engine.py`, функция `arabic_parts()`

**Файл**: `astro_engine.py`, функция `arabic_parts`

**Текущая формула**: `ASC + DSC_ruler − Venus`

**Проблема**: `DSC_ruler` — управитель знака Десцендента. В этой формуле нет
стандартного обоснования ни в одной из традиций.

**Правильные формулы** (традиционные, по Бонатти и Аль-Бируни):
```python
# Мужская карта (дневная):
lot_of_marriage_male_day   = ASC + Venus - Saturn
# Мужская карта (ночная):
lot_of_marriage_male_night = ASC + Saturn - Venus

# Женская карта (дневная):
lot_of_marriage_female_day   = ASC + Mars - Moon  # "Part of Husbands"
# Женская карта (ночная):
lot_of_marriage_female_night = ASC + Moon - Mars

# Упрощённая универсальная (Роберт Золлер):
lot_of_marriage_universal = ASC + DSC - Venus  # т.е. ASC + (ASC+180°) - Venus
```

Нужно добавить параметр `sect` и `gender` в функцию, либо возвращать все варианты.

**Реализовано**: функция теперь возвращает все три варианта:
`marriage` (Zoller/универсальный), `marriage_male` (Bonatti, с учётом секты),
`marriage_female` (Bonatti, с учётом секты).

### 5. ⏳ НЕ РЕАЛИЗОВАНО — Орбы в натальной карте — 8° для трина/оппозиции завышены

**Файл**: `astro_engine.py`, таблица аспектов

Орб 8° для трина, квадрата и оппозиции — это широкий стандарт. Проблема в том,
что система не учитывает **световые орбы**: Солнцу и Луне традиционно дают
расширенные орбы (до 10°), остальным планетам — меньше (5-6° для трина).

**Рекомендуемые орбы по традиции**:
```python
ORBS = {
    "conjunction":  {"sun": 10, "moon": 10, "personal": 8, "social": 6, "outer": 5},
    "opposition":   {"sun": 10, "moon": 10, "personal": 7, "social": 6, "outer": 5},
    "trine":        {"sun": 8,  "moon": 8,  "personal": 6, "social": 5, "outer": 4},
    "square":       {"sun": 8,  "moon": 8,  "personal": 6, "social": 5, "outer": 4},
    "sextile":      {"sun": 6,  "moon": 6,  "personal": 5, "social": 4, "outer": 3},
    "quincunx":     {"all": 3},
    "semisextile":  {"all": 2},
    "semisquare":   {"all": 2},
    "sesquiquadrate": {"all": 2},
}
# Орб двух планет = среднее их индивидуальных орбов
def get_orb(p1, p2, aspect_type):
    return (ORBS[aspect_type][planet_class(p1)] + ORBS[aspect_type][planet_class(p2)]) / 2
```

**Слой 3 — Текущий фон (медленные транзиты как фон периода)**
