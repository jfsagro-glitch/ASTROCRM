### 3.2 Планеты и точки

#### Функция расчёта: `calc_planets(JD)`

Возвращает `{planet_name: longitude_degrees}` для всех тел.

| Тело | Метод расчёта | Примечание |
|------|--------------|-----------|
| Солнце (`sun`) | VSOP87 + собственная реализация | Возвращает (долготу, радиус-вектор) |
| Луна (`moon`) | Meeus таблицы + периодические члены | Высокая точность |
| Меркурий (`mercury`) | Кеплер + гелиоцентрические поправки | |
| Венера (`venus`) | VSOP87 | |
| Марс (`mars`) | VSOP87 | |
| Юпитер (`jupiter`) | VSOP87 | |
| Сатурн (`saturn`) | VSOP87 | |
| Уран (`uranus`) | VSOP87 | |
| Нептун (`neptune`) | VSOP87 | |
| Плутон (`pluto`) | Интерполяция по таблице | |
| Северный узел (`node`) | Средний узел | |
| Истинный узел (`true_node`) | Периодические поправки | |
| Лилит (`lilith`) | Средняя чёрная Луна | |
| Хирон (`chiron`) | Интерполяция по таблице | |

> При наличии `pyswisseph` все расчёты переключаются на Swiss Ephemeris (точность < 1″).

#### Поля каждой планеты в ответе

```python
{
  "lon":          float,       # эклиптическая долгота 0–360°
  "sign":         str,         # название знака (aries…pisces)
  "glyph":        str,         # символ знака (♈…♓)
  "deg":          int,         # градусы внутри знака (0–29)
  "min":          int,         # минуты дуги (0–59)
  "deg_min":      str,         # строка "14°22′"
  "retrograde":   bool,        # ретроградность
  "house":        int,         # дом (1–12)
  "dec":          float,       # склонение в градусах
  "oob":          bool,        # вне границ (out of bounds, |dec|>23.5°)
  "speed":        float,       # скорость °/день
  "speed_status": str,         # stationary|retrograde|slow|average|fast
  "decan":        int,         # декан (1–3)
  "decan_ruler":  str,         # планета-управитель декана
  "term_ruler":   str,         # планета-управитель термы (египетская)
  # только для Луны:
  "mansion_num":  int,         # лунная стоянка 1–28
  "mansion_name": str,         # название стоянки
  "mansion_nature": str        # benefic|malefic|neutral
}
```

### 3.3 Системы домов

**Функция**: `calc_houses(JD, lat, lon, system="placidus")`

| Система | Метод | Особенность |
|---------|-------|-------------|
| `placidus` | Трисекция квадрантов по времени | Стандарт западной астрологии |
| `equal` | 30° от ASC | Простота, популярно в Индии |
| `whole_sign` | Знак = дом (от ASC) | Древнегреческий метод |
| `porphyry` | Трисекция квадрантов по дуге | Упрощённый Плацидус |
| `koch` | Косое восхождение | Популярен в немецкой традиции |

Возвращает долготы домов h1–h12, MC (h10), IC (h4), Vertex, Anti-Vertex.

#### Поля каждого куспида дома

```python
{
  "lon":      float,
  "sign":     str,
  "glyph":    str,
  "deg":      int,
  "min":      int,
  "deg_min":  str
}
```

### 3.9 Традиционные техники

#### Деканы
- `calc_decan(lon)` → (деканный номер 1–3, планета-управитель)
- Используется таблица Халдейских управителей

#### Египетские термы
- `calc_term_ruler(lon)` → планета-управитель термы

#### Лунные стоянки
- `lunar_mansion(moon_lon)` → (номер 1–28, название, природа: benefic/malefic/neutral)

#### Диспозиторы
- `calc_dispositors(planets_raw)` → {карта диспозиций, цепи, взаимные управления, конечные диспозиторы}

#### Деклинации и скорости
- `calc_declinations(planets_raw, JD)` → {планета: склонение}
- `calc_speeds(planets_raw, JD)` → {планета: (скорость °/день, статус)}
  - Статусы: stationary, retrograde, slow, average, fast

#### Неподвижные звёзды
- `calc_fixed_stars(JD, planets_raw, orb=1.0)` → список соединений с 30 главными звёздами
  - С координатами J2000, прецессией, природой и звёздной величиной

#### Секта (дневная/ночная карта)
- `calc_sect(planets_raw, houses_dict)` → (секта, {планета: статус секты})
  - Дневная карта: Солнце над горизонтом
  - Ночная карта: Солнце под горизонтом
  - Статусы: in_sect, out_of_sect, None

#### Вертекс и Анти-Вертекс
- `calc_vertex(ramc, lat, eps)` → (вертекс, анти-вертекс) — дополнительные точки

#### Опциональные расчёты (через флаги)
- `include_midpoints=True` → таблица мидпоинтов всех пар планет
- `include_antiscia=True` → антисции и контрантисции
- `include_fixed_stars=True` → соединения с неподвижными звёздами

## 4. ПРЕДИКТИВНЫЕ ТЕХНИКИ

**Файл**: `astro_predictive.py`

### 4.1 Вторичные прогрессии

**Функция**: `secondary_progressions(natal_jd_utc, lat, lon, target_date_str, houses_system)`

- **Принцип**: 1 день после рождения = 1 год жизни
- **Формула**: `prog_JD = natal_JD + прожитые_лет`
- **Возвращает**: прогрессированные планеты, дома, натальные планеты, аспекты (прогр.→натал.)

### 4.2 Дирекции Солнечной дуги (Solar Arc)

**Функция**: `solar_arc(natal_jd_utc, lat, lon, target_date_str, houses_system)`

- **Принцип**: Дуга = прогрессированное Солнце − натальное Солнце; все планеты сдвигаются на эту дугу
- **Возвращает**: направленные планеты, дома, аспекты (напр.→натал.)

### 4.3 Солярный возврат

**Функция**: `solar_return(natal_jd_utc, return_year, lat, lon, houses_system)`

- **Принцип**: Точный момент возврата Солнца к натальной позиции в заданном году
- **Алгоритм**: Бинарный поиск по JD до точности < 1 секунды
- **Возвращает**: полная карта на момент возврата (планеты, дома, аспекты, дата/время)

### 4.4 Лунный возврат

**Функция**: `lunar_return(natal_jd_utc, near_date_str, lat, lon, houses_system)`

- **Принцип**: Ближайший момент возврата Луны к натальной позиции
- **Диапазон поиска**: ±14–28 дней от целевой даты
- **Возвращает**: полная карта на момент возврата

### 4.5 Профекции

**Функция**: `profections(natal_jd_utc, target_date_str, houses_system, lat, lon)`

- **Принцип**: Каждый год жизни активирует следующий дом по Халдейскому порядку, начиная с 1-го
- **Цикл**: H1 → H2 → ... → H12 → H1 (каждые 12 лет)
- **Возвращает**:
  - Возраст (полных лет)
  - Годовой дом, знак, управитель
  - Месячный дом, знак, управитель
  - Натальная позиция годового управителя

### 4.6 Транзиты

**Функция**: `transits(natal_jd_utc, target_date_str, target_time_str, lat, lon, transit_orb_major, transit_orb_minor)`

- **Орбы**: Мажорные аспекты — 1.0°, минорные — 0.5°
- **Флаги**: applying/separating
- **Возвращает**: транзитные планеты, натальные планеты, список аспектов

### 4.7 Третичные прогрессии

**Функция**: `tertiary_progressions(natal_jd_utc, target_date_str, lat, lon, houses_system)`

- **Принцип**: 1 лунный месяц (27.321582 дня) = 1 год жизни
- **Формула**: `prog_JD = natal_JD + лет × 27.321582`

### 4.8 Конверсные прогрессии

**Функция**: `converse_progressions(natal_jd_utc, target_date_str, lat, lon, houses_system)`

- **Принцип**: Движение назад от рождения; 1 день до = 1 год жизни
- **Формула**: `prog_JD = natal_JD − прожитые_лет`

### 4.9 Пренатальное сизигие

**Функция**: `prenatal_syzygy(natal_jd)`

- **Находит**: последнее Новолуние (угол ≈ 0°) или Полнолуние (угол ≈ 180°) перед рождением
- **Возвращает**: `{type, jd, date_str, sun_lon, moon_lon}`

### 4.10 Затмения

**Функция**: `find_eclipses(start_date_str, count=5)`

#### Классификация солнечных затмений

| Тип | Условие (расстояние от узла) |
|-----|------------------------------|
| Полное/Кольцеобразное | dist_node < 10° |
| Частное | dist_node < 15° |
| Полутеневое | dist_node < 18.5° |

#### Классификация лунных затмений

| Тип | Условие |
|-----|---------|
| Полное | dist_node < 4.5° |
| Частное | dist_node < 9.5° |
| Полутеневое | dist_node < 12.5° |

**Возвращает**: `{type, eclipse_class, date_str, jd, sun_lon, moon_lon, node_lon, dist_node}`

### 4.11 Станции планет

**Функция**: `find_stations(planet_name, start_date_str, end_date_str)`

- **Определение**: Смена знака скорости (через 1-дневную конечную разность)
- **Уточнение**: Бисекция до высокой точности
- **Типы**: `station_retrograde` (прямо→ретро), `station_direct` (ретро→прямо)
- **Возвращает**: `{planet, type, date_str, jd, lon, sign}`

### 4.12 Точные даты транзитных аспектов

**Функция**: `transit_exact_dates(natal_jd_utc, from_date_str, to_date_str, lat, lon)`

- **Метод**: Находит момент, когда орб транзита пересекает ноль (применяется → разделяется)
- **Возвращает**: `{transit_planet, natal_planet, aspect, glyph, exact_date_str, jd, lon_at_exact}`

### 4.13 Карта ингресса

**Функция**: `ingress_chart(year, sign_name_or_lon, lat, lon_geo, houses_system)`

- **Метод**: Точный момент входа Солнца в указанный знак (0° Овна = весеннее равноденствие)
- **Возвращает**: Полная карта на момент ингресса с `ingress_metadata`

### 4.14 Таблица эфемерид

**Функция**: `ephemerides_table(start_date_str, days=30, time_str="12:00")`

- **Максимум**: 120 дней
- **Порядок планет**: sun, moon, mercury, venus, mars, jupiter, saturn, uranus, neptune, pluto, true_node, node, lilith, chiron
- **Поля на каждую планету**: lon, sign, deg_min, speed_deg_day, retrograde

### 4.15 Общий астро-прогноз (AstroSummary)

**Функция**: `astro_summary(target_date_str, time_utc="12:00")`

- **Периоды**: день, неделя, месяц, год
- **Поля**: знак Солнца, знак Луны, ключевые аспекты, энергия (supportive/tense/mixed), фокус, совет, настроение

### 4.16 Ректификация времени рождения

**Функция**: `rectify_birth_time(date_str, time_str, lat, lon, utc, events, range_minutes=180, houses_system)`

- **События**: список `{type, date, time}`, где type = marriage, career_peak, children_birth и др.
- **Алгоритм**: Грубая сетка → тонкая сетка → финальное уточнение
- **Скоринг**: транзиты + прогрессии + профекции к целевым планетам событий
- **Возвращает**: ректифицированное время, уверенность (%), вердикт, топ-кандидаты, диагностика событий

| ASC (Восход) | Зависящая от широты кривая, где планета восходит |
| DSC (Закат) | Зависящая от широты кривая, где планета заходит |

```json

    "ic_lon": float,

    "planet_lon": float,
    "planet_sign": str
  }
}
```

**Функция**: `local_space(natal_jd_utc, obs_lat, obs_lon)`

- **Метод**: Экваториальные координаты (RA/Dec) → горизонтальные (Az/Alt) через LST

**Возвращает** для каждой планеты:
```json
{
  "planet": {
    "azimuth": float,       // 0–360°, N=0°, по часовой стрелке
    "altitude": float,      // -90° до +90°
    "ra": float,            // прямое восхождение
    "dec": float,           // склонение
    "above_horizon": bool,
    "planet_lon": float,
    "planet_sign": str
  }
}
```

### 6.4 Параны

**Функция**: `parans(natal_jd_utc, paran_lat, orb_deg=1.0)`

- **Паран**: две планеты одновременно на разных углах (восход, заход, кульминация, антикульминация) на одной широте
- **Возвращает**: список `{planet1, angle1, planet2, angle2, lon_separation, planet1_lon, planet2_lon}`

## 9. ВСПОМОГАТЕЛЬНЫЕ МОДУЛИ

### 9.1 astro_time.py — Временные утилиты

| Функция | Назначение |
|---------|-----------|
| `delta_t_seconds(year, month, day)` | Delta T = TT − UT в секундах (модель Эспенака/Мееуса) |
| `n360(d)` | Нормализация угла к диапазону 0–360° |
| `T(jd)` | Юлианские века от J2000: `(jd − 2451545.0) / 36525` |
| `decimal_year(year, month, day)` | Дата как десятичная доля года |
| `is_leap_year(year)` | Проверка високосного года |
| `days_in_month(year, month)` | Количество дней в месяце |

### 9.2 astro_calibrate.py — Калибровка

- **Назначение**: Массовая калибровка точности расчётов против датасета AstroDatabank
- **Метод**: Чтение базы SQLite3 с известными временами рождений и событиями → скоринг расчётов → валидация точности движков

### 9.3 server/aiProxy.ts — AI-прокси (Express.js)

- **Порт**: 8787 (env `AI_PROXY_PORT`)
- **Модель**: Google Gemini 2.5 Pro
- **Эндпоинт**: `POST /api/generate-json` — структурированная генерация JSON по шаблону
- **Переменные**: `GEMINI_API_KEY`, `APP_URL`
- **Фича**: может раздавать фронтенд-билд (`frontend/dist`)

### Переменные окружения

| Переменная | Где | Описание |
|-----------|-----|---------|
| `VITE_API_URL` | `frontend/.env.local` | URL FastAPI бэкенда |
| `VITE_FIREBASE_*` | `frontend/.env.local` | Firebase конфигурация |
| `GEMINI_API_KEY` | `.env.local` (root) | Ключ Google Gemini API |
| `AI_PROXY_PORT` | `.env.local` (root) | Порт AI-прокси (по умолч. 8787) |
| `APP_URL` | `.env.local` (root) | Публичный URL прокси |

### Railway (production)

- Конфигурация: `railway.toml`, `nixpacks.toml`
- Автоматический деплой из `main` ветки
- FastAPI раздаёт фронтенд-билд (`frontend/dist/`) как статику с SPA-фолбеком
- Кеширование статики: 1 час

### Firebase

- **Firestore**: Хранение профилей клиентов и консультаций
- **Auth**: Авторизация пользователей
- **Схема**: `firebase-blueprint.json` (сущности Client + Consultation)
- **Правила**: `firestore.rules`
- **Индексы**: `firestore.indexes.json`

### Требования к системе

- Node.js 18+
- Python 3.11+
- `pyswisseph` (опционально, для высокоточных расчётов)
- Файлы Swiss Ephemeris в директории `ephe/` (загружаются через `/ephemeris/download`)
